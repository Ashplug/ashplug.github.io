# ASHPLUG presentation

The Reveal.js deck is served from the GitHub Pages output directory:

- Local path: `docs/presentation/`
- Public URL: <https://ashplug.com/presentation/>

Open `index.html` in a browser or run the website's dev server from the site
repository and navigate to `/presentation/`.

The deck uses Reveal.js 5.2.1 from jsDelivr and locally bundled ASHPLUG logo and
font assets. A network connection is required to load Reveal.js. Use the arrow
keys or space to navigate; press `S` for speaker notes and `O` for overview.
The URL hash tracks the current slide. Reveal.js's `?print-pdf` option can be
used in a compatible browser to print/export the deck.

Brand font licenses are included in the branding repository. This folder
contains presentation-specific copies of the font files and logos so the deck
assets remain alongside the presentation.
