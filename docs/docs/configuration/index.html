Configuration

Ashplug reads TOML configuration and applies environment overrides before validating the effective settings.

Configuration location

Resolution order is explicit CLI path, ASHPLUG_CONFIG, $XDG_CONFIG_HOME/ashplug/config.toml, then ~/.config/ashplug/config.toml. A missing file uses built-in defaults.

inspect configuration
ashplug config init
ashplug config show
ashplug config path

Important sections

[ai]provider, base_url, model, API-key environment variable, timeout, retries, and fallback provider.
[execution]mode, step limit, command timeout, output limit, working directory, and optional Linux sandbox.
[safety]privileged/interpreter policy, write approval, unknown command policy, and allowed write roots.
[history]SQLite persistence toggle and database path.

Execution modes

hybrid runs read-only commands automatically and asks for approval for writes. plan_only evaluates without executing. automatic approves commands permitted by safety policy.
