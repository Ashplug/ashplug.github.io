CLI commands

The top-level form accepts a task; management subcommands expose planning, configuration, history, and shell integration.

common commands
ashplug "find large files"
ashplug plan "list files"
ashplug config show
ashplug history list
ashplug init bash

Useful options

--provider NAMEOverride the configured provider: openai, ollama, or mock.
--model MODELOverride the model name.
--planProduce a plan and show safety decisions without executing.
--yesApprove every command the policy permits for this invocation.
--no-historyKeep this invocation out of persistent history.

Exit codes

0 indicates success, 1 runtime/provider/safety failure, 2 invalid CLI usage, and 3 an unimplemented feature.
