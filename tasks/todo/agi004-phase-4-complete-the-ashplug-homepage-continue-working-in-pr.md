# # PHASE 4 — Complete the Ashplug Homepage

Continue working in:

`~/projects/ashplug/`

The following are already implemented and approved:

- Design system.
- Branding.
- Typography.
- Navigation.
- Theme switcher.
- Homepage hero.
- Installation command.
- Animated terminal demonstration.

Your task is to complete the homepage without changing the approved visual direction.

## 1. Homepage narrative

Maintain this order:

1. Hero.
2. Animated terminal demonstration.
3. Product features preview.
4. Open-source / GitHub section.
5. Final installation CTA.
6. Footer.

Keep the homepage focused.

Do not add unnecessary marketing sections.

## 2. Features preview

Inspect the source code and select the most important real Ashplug capabilities.

Present them in a visually consistent way.

Each feature should have:

- A concise title.
- A practical explanation.
- An example where useful.

Include a link to the dedicated Features page.

Do not invent functionality.

## 3. GitHub section

Use the verified repository URL.

Display:

- GitHub repository link.
- Star CTA.
- Live star count.
- Latest release information if available.

Use the GitHub API from client-side JavaScript.

Implement:

- Loading state.
- Error handling.
- Rate-limit handling.
- Graceful fallback.
- No fabricated numbers.

The homepage must remain functional if the GitHub API is unavailable.

Do not introduce a backend.

## 4. Final CTA

Provide a clear invitation to install Ashplug.

The installation command should remain the primary action.

GitHub can be the secondary action.

Avoid unnecessary button combinations.

## 5. Footer

Include:

- Ashplug wordmark.
- Short product description.
- Features.
- Installation.
- Documentation.
- GitHub.
- Contributing links where available.
- Open-source acknowledgment.

Do not invent social media accounts.

## 6. Completion checkpoint

Verify the complete homepage in:

- Dark theme.
- Light theme.
- Desktop.
- Tablet.
- Mobile.

Check all links and interactions.

Ensure the page maintains a coherent visual rhythm.

Stop after completing the homepage.

Wait for approval before proceeding to Phase 5.
